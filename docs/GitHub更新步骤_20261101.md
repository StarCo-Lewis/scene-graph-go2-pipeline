# 更新已有 GitHub 仓库

1. 解压本源码 ZIP。在你此前已经配置 origin 的本地仓库中，先检查并保留自己的未提交改动。
2. 将解压后根目录的内容复制到已有仓库根目录，覆盖对应旧源码；保留已有 `.git`。本包本身不含 `.git`。若某个文件已有你或同学的独立改动，先比较合并，不直接覆盖。
3. 在该已有仓库根目录的 PowerShell 执行：

```powershell
git status --short
git diff --stat
git diff --check
git add .
git diff --cached --stat
git commit -m "Update U87 metadata binding and semantic collection safeguards"
git push origin main
git rev-parse HEAD
```

以上由用户执行，本次打包没有提交、推送或修改远端。最后的真实 commit SHA 可发给导航组，并附本包三个运行文件 SHA 和 PACKAGE_MANIFEST；它们位于 docs/版本更新_20261101.md。若复制后又修改了发布文件，应重新生成对应 manifest，不继续使用旧指纹。
